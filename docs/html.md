# HTML documentation

## Purpose

The HTML tree is a versioned, static publication artifact generated by the
owner repository. It combines canonical Markdown rendered by Pandoc and public
API documentation rendered by Doxygen.

HTML generation is disabled by default. Ordinary library builds and package
installs do not depend on Pandoc or Doxygen.

## Output layout

With `-Dhtml_docs=enabled`, the build produces:

```text
build/docs/html/libpkgcatalog-acquire/3.0.2/
├── index.html
├── architecture.html
├── abi.html
├── protocols/
├── history/
├── man/
├── api/
├── assets/
└── legal/
```

The checker rejects broken local links, escaped Markdown links, paths outside
the artifact, absolute source/build paths, and missing required pages.

## Installation

The artifact installs under:

```text
${prefix}/share/htmldocs/libpkgcatalog-acquire/3.0.2/
```

Use the `html-docs` install tag for selective staging. The project-owned install
script consumes `MESON_INSTALL_DESTDIR_PREFIX`, so normal Meson `DESTDIR` and
`--destdir` semantics apply.

## Site publication

A website may copy and serve the installed version directory. It must not rerun
Pandoc or Doxygen, rewrite parser contracts, or reconstruct documentation from
headers independently.

Each repository remains the authority for its generated HTML. The site owns
indexing, navigation across projects, and publication only.
